v1: Dashboard UI mock for Fleetly fleet management app. Audience: operations managers. Language: English. Layout: fixed left sidebar nav (Dashboard, Vehicles, Routes, Reports, Settings), top bar with search, user avatar, and dark/light toggle. Main content: stats row (4 cards: Active Vehicles, Deliveries Today, Avg Delivery Time, Alerts), large map placeholder showing vehicle locations, vehicles table with columns: Plate Number, Driver, Status, Last Location, Fuel Level. Style: clean, modern, B2B SaaS dashboard. Primary accent #0EA5E9 (sky blue) for highlights, buttons, links, active states. Dark/light mode supported. Use Inter font. Focus on clarity and data density.
